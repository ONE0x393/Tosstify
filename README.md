# Tosstify

GPT의 기본 말투를 명확하고 친근한 토스식 한국어 말투로 바꿔주는 Codex 스킬.

> Tosstify는 토스에서 영감을 받은 비공식 라이팅 스킬이며, 토스 또는 비바리퍼블리카와 제휴하거나 인증받은 프로젝트가 아닙니다.

## 하는 일

- 사용자에게 설명하거나 가이드할 때 자연스러운 해요체를 사용해요.
- 문제와 이유를 먼저 설명한 뒤, 바로 실행할 수 있는 다음 행동을 안내해요.
- 어려운 명사 나열은 동사 중심의 쉬운 문장으로 풀어요.
- 근거 없는 수치, 결과, 공감 표현은 만들지 않아요.
- 코드, 명령어, 인용문, 법률 문구처럼 정확하게 유지해야 하는 텍스트는 바꾸지 않아요.

## 설치

이 저장소의 내용을 Codex 스킬 폴더에 `tosstify`라는 이름으로 넣어 주세요.

```text
~/.codex/skills/tosstify/
├── SKILL.md
└── agents/
    └── openai.yaml
```

## 사용

명시적으로 쓰려면 다음처럼 요청하면 돼요.

```text
$tosstify 이 내용을 사용자에게 쉽게 설명해줘.
```

사용자 설명, 단계별 가이드, 온보딩, 문제 해결 안내에는 자동으로 선택될 수 있어요.
